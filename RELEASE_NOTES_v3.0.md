# Astra 3.0 Beta

Версия-кандидат: `3.0.0-beta.1`
Статус: локальный кандидат; не опубликован и пока не принят по реальному голосу.

## Что вошло в этап

- Быстрый ответ через локальную Ollama: повторные model/metadata checks кешируются, ответ по умолчанию идёт без дополнительного thinking, а после подтверждённой wake-фразы Astra в фоне подготавливает только уже установленную модель. Скачивания модели и cloud fallback нет.
- Ограниченный голосовой путь: сетевое распознавание STT имеет тайм-аут 12 секунд по умолчанию; замер отдельно показывает захват, сетевое распознавание и полный путь.
- Ограниченный Edge TTS: прямое воспроизведение имеет общий лимит 25 секунд по умолчанию; основной и резервный голос делят один бюджет.
- Cache miss больше не вызывает вторую синхронную генерацию уникального mp3. Timing-записи LLM и STT не включают текст вопроса или распознанную команду.
- Добавлен локальный `tools/latency_report.py`: он считает p50/p95 уже существующих компонентных замеров и не показывает текст лога; end-to-end wake → первый слышимый звук он не подменяет.
- Файловый поиск из локального плана опрашивает отмену пользователя и общий deadline во время обхода каталога; результаты после отмены не выдаются как успешное завершение.
- Чтение файлового шага использует тот же deadline и проверяет отмену между частями разбора PDF, DOCX, XLSX и PPTX; один системный I/O или вызов парсера не прерывается посередине.
- Отмена или отзыв доступа в локальном File RAG останавливает чтение и отбор фрагментов; если отмена пришла во время чтения, вопрос не отправляется Ollama.
- Голосовой вопрос по точному имени одного файла работает только в открытой выбранной папке с отдельным default-deny `ask_files`, локальным Ollama и включённым Windows SAPI. Ограниченные цитаты передаются только localhost Ollama; ответ произносится через приватный SAPI без содержимого в чате/логах или облачном TTS. Проверены запрет без разрешения, запрет облачного профиля, а также отмена при закрытии папки и переключении режима.
- Предыдущие изменения 2.10 собраны в этот крупный этап; отдельной 2.10 Beta не выпускаем.

## Проверки

- Локально прошли компиляция, 216 unit/integration/UI тестов, 9 smoke tests, 4 config validators и Astra Doctor.
- Ранее установленная `qwen3:4b` локально прогрета через localhost за 11 секунд; модель не скачивалась. Это единичный замер прогрева модели, не измерение полного ответа.
- Базовый voice-core, кооперативная отмена поиска/чтения/File RAG и локальный отчёт задержек прошли GitHub Windows CI `43489284075`, `43493497060`, `43495159745`, `43496136563` и `43498745535`, включая portable-package validation; документационный commit прошёл `43497299929`.
- Документационный CI `43499930483` выявил два хрупких теста точного сравнения float для TTS-бюджета; заменил их сравнением с допуском `1e-6`. Все 24 теста voice-latency suite прошли локально; новая полная CI-проверка ожидается после push.
- Полный локальный gate текущей ревизии прошёл: compileall, desktop/runtime compilation, 292 unit/UI/runtime tests, 9 smoke tests, 4 config validators и Astra Doctor. Сборка portable ZIP/установщика и Windows CI именно этого изменения ожидаются после push.

- Проверить речь женским и мужским голосом и выбрать приемлемое качество вместе с Егором.
- UI, desktop-приложение, иконка и 2D/3D-аватары в этом этапе не менялись.
