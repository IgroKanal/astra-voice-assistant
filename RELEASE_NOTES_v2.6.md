# Astra 2.6 Beta · поиск команд

Версия приложения: `2.6.0-beta.1`.

## Что появилось

- Кнопка «Команды» открывает поиск примеров по категориям: основные команды, приложения и сайты, музыка, окна и напоминания.
- У каждой команды есть краткое описание. Каталог включает только фразы, которые распознаёт локальный парсер Astra.
- Нажатие «Вставить в чат» добавляет настроенное имя персонажа и выбранную фразу в поле ввода. Astra не запускает её, пока пользователь сам не нажмёт «Отправить».
- Справка голосом объясняет, как начать новый диалог.

## Проверки и открытые пункты

Полный Windows gate прошёл: 171 тест. Portable ZIP прошёл scan/relocated-runtime/package проверки; установщик прошёл установку, запуск runtime и удаление с сохранением пользовательских данных. Реальная визуальная приёмка каталога и проверка микрофона остаются открытыми.
