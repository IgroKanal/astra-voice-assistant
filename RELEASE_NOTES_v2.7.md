# Astra 2.7 Beta

**Версия:** `2.7.0-beta.1`

## Что изменилось

- В окне истории действий появился поиск по названию действия, его техническому типу и исходу.
- Добавлен фильтр по разрешённым, заблокированным, завершённым, ошибочным и отменённым операциям.
- Поиск не учитывает регистр и разницу между «ё» и «е»; список обновляется сразу при изменении фильтра.
- История продолжает показывать только время, тип события и исход. Команды пользователя, аргументы, пути и содержимое файлов не записываются в неё.

## Границы проверки

Автоматические проверки Windows UI подтверждают поиск, фильтрацию, обновление и отсутствие пользовательских деталей в строках таблицы. Реальный визуальный осмотр, работа клавиатурой и микрофоном требуют отдельной ручной приёмки. Astra 2.7 остаётся Beta и не закрывает общие критерии v2–v5.
