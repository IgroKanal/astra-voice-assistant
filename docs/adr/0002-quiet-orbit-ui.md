# ADR 0002 — Quiet Orbit: визуальная система без смены UI-стека

Дата: 2026-11-14. Статус: принято для рабочей Windows-копии Astra 3.1.

## Контекст

Astra уже имеет изолированный worker, typed JSON events, DPAPI-профиль, Tk-окна, четыре оригинальных 2D-персонажа и отдельный Godot preview. Требуется продуктовая визуальная иерархия, доступные настройки и предсказуемый 2D fallback без изменения разрешений, STT/TTS/LLM или action engine.

## Решение

Сохранить Tkinter. Направление **Quiet Orbit** использует глубокий синий фон, холодные сиреневый и бирюзовый акценты, Segoe UI, одноуровневые карточки и спокойные отступы. Фирменная иконка Astra не меняется.

- Главный экран делится на навигацию, карточку персонажа и диалог. Микрофон имеет постоянный явный статус; Voice остаётся отдельным действием.
- `desktop_theme.py` содержит общие токены и стили native/ttk controls. Кнопки имеют keyboard focus и hover, не зависящий только от цвета текста.
- Настройки включают «Студию персонажа» и «Внешний вид». Имя, персонаж, голос и 2D/3D выбор preview'ируются до Save; Cancel закрывает окно без записи.
- Профиль версии 1 получает optional `avatar_mode`, `ui_scale`, `reduced_motion`. Старые записи загружаются через dataclass defaults; значения строго валидируются.
- 2D остаётся встроенным основным представлением. 3D запускается только явной кнопкой в существующем отдельном Godot-процессе. Отсутствие Godot или слабый GPU не блокирует приложение.
- Reduced motion отключает плавание и пульсацию. Масштаб 100/110/125/150% применяется при следующем запуске поверх Windows DPI.

## Почему не PySide6 или WinUI

Миграция потребовала бы нового packaging/runtime слоя, повторной проверки всех панелей, accessibility и installer integration. Текущая задача решается shared Tk styles и композицией без смены контрактов. Новый стек не даёт сам по себе production 3D-модель или lip-sync, поэтому миграция сейчас не оправдана.

## Последствия и границы

Tk сохраняет ограничения native window rendering и не встраивает Godot в главное окно. Процедурный 3D blockout не объявляется production-моделью. Художественная приёмка, реальные голоса, GPU и Windows scaling остаются ручными gates. Пользовательский импорт персонажей не добавляется без отдельной безопасной спецификации.
