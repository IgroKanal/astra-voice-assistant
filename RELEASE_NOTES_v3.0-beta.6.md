# Astra 3.0 Beta.6 — локальный кандидат

- **Версия:** `3.0.0-beta.6`
- **Статус:** локальная непубликованная сборка. Полный автоматический gate прошёл; Windows CI `43578645878` и `43578652996` успешно собрали portable ZIP и проверили установщик.

## Изменения

- Выбранные `.html` и `.htm` файлы можно читать внутри уже разрешённой пользовательской папки.
- Извлечение возвращает обычный текст и ограничено общим лимитом текстовых файлов 1 МБ. Скрипты не исполняются, внешние ресурсы не загружаются.
- Исключаются `head`, script/style, noscript, template, SVG/canvas, iframe/object/embed, элементы с `hidden`/`aria-hidden="true"` и inline CSS `display:none`/`visibility:hidden`.
- Чтение не добавляет HTML к типам, которые Astra может открыть голосовой командой. File RAG принимает HTML только как выбранный документ и сохраняет пометку, что текст документа недоверенный.

## Проверки

- Полный локальный gate: **333 unit/integration/UI tests**, compileall и py_compile, 9 smoke-проверок, 4 валидатора конфигурации и Astra Doctor.
- Доктор оставил только прежнее некритичное предупреждение: служба AmneziaWG не найдена.
- Оба Windows CI прогона прошли сборку и валидацию portable ZIP и установщика.
- Реальные микрофон, голосовое чтение, выбор качества голоса и p50/p95 от wake-фразы до первого звука остаются открытыми.

Beta.6 остаётся непубличным кандидатом; GitHub release и переключение рабочего ярлыка не выполнялись.
