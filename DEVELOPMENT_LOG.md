### Реализовано

- Desktop Preview: Tk окно, тёмная тема, анимированный 2D-персонаж, чат, быстрые команды, пауза и переключение голоса.
- Отдельный runtime с очередью событий, ограничением очереди и протоколом JSON v1.
- Микрофон включается только явно; статусы listening/recognizing/speaking и транскрипция видны в чате.
- Исправлена гонка закрытия окна во время запуска runtime; restart после закрытия запрещён.
- Файловая область только для чтения: выбрать корень, искать по имени, читать UTF-8 до 1 МБ. Blocklist секретов, запрет traversal/absolute paths/reparse points, повторная проверка identity после чтения.
- Явная память заметок: SQLite, содержимое зашифровано Windows DPAPI, просмотр/поиск/забывание; LLM эти заметки пока не получает.
- Portable build: Astra.exe + отдельный AstraRuntime.exe с Python и зависимостями, конфигурация без личного .env.
- Build dependencies отделены от runtime requirements.
- Добавлена Windows CI-конфигурация; на GitHub пока не опубликована и там не запускалась.

## Следующий проход · action policy и graceful close

- Удалены оба пути taskkill /F из WindowsAppManager. Закрытие идёт через WM_CLOSE ровно одному окну с точным process name и повторной проверкой PID. Неоднозначность без активного окна останавливает закрытие.
- Результат различает отправленный запрос и фактически исчезнувшее окно; media shutdown больше не заявляет успешное закрытие заранее. Закрытие окна не равнозначно завершению tray-процесса.
- ActionPolicy проверяет тип, размеры аргументов, confidence, источник и scope перед handle_action. Runtime wake checks остаются отдельным обязательным слоем.
- Прикладные scopes сохраняются в encrypted profile, доступны отдельной вкладкой UI и применяются даже в env-режиме. Legacy-навыки по умолчанию разрешены как раньше; можно отозвать любой scope.
- Отдельные gates покрывают browser shortcuts и media, которое запускает/закрывает приложение. Routine проверяет разрешение каждого шага.
- Добавлены 5 graceful-close tests, 7 policy tests и persistence test permissions. Реальные пользовательские окна не закрывались тестами; manual WinAPI/app/save-dialog gate остаётся необходимым.
- После проверки native policy распространён на обычный console/hidden runtime: сохранённые права не должны обходиться выбором старого launcher. Явный developer ignore flag оставлен только для изолированных тестов.
