# Astra 3.0 Beta.5 — локальный кандидат

- **Версия:** `3.0.0-beta.5`
- **Статус:** локальная непубликованная сборка. Автоматический gate, portable ZIP и изолированный установщик прошли.

## Изменения

- При ошибке Edge TTS Astra лениво инициализирует Windows SAPI и пробует установленный русский локальный голос. Если локального голоса нет или он не может произнести кириллицу, текстовый ответ остаётся доступен, а ошибка озвучки сообщается честно.
- После неудачных сетевых попыток Edge TTS временно открывает 90-секундный circuit breaker. В этот период новые уникальные фразы идут через локальный SAPI без повторного сетевого ожидания. Уже имеющийся аудиокэш по-прежнему воспроизводится локально.
- Инициализация и воспроизведение SAPI сериализованы блокировкой; ошибочная инициализация не повторяется на каждом ответе.

## Проверки

- Полный локальный Windows gate: **324 unit/integration/UI tests**, compileall и py_compile, 9 smoke-проверок, 4 валидатора конфигурации и Astra Doctor.
- Astra Doctor оставил только некритичное предупреждение: служба AmneziaWG не найдена.
- Portable ZIP прошёл проверку структуры/секретов; замороженный runtime обработал локальные команды, сброс диалога и безопасное журналирование. Edge TTS helpers отвечают на offline `--version`/`--help` проверки.
- Установщик прошёл изолированную установку, runtime-проверку и удаление; тестовые данные LocalAppData сохранились.
- В системе найден русский голос Windows SAPI. Слышимая оценка голоса и ручная проверка фактического fallback не выполнялись.

## Открытые проверки

- Edge TTS в этой среде перечисляет голоса, но синтез возвращает `NoAudioReceived`; онлайн-голос и его доступность требуют повторной проверки.
- Реальный микрофон, субъективная оценка голосов, установленные модели Ollama и замеры p50/p95 от wake-фразы до первого звука не проверены.
- Установка beta.5 в пользовательскую папку и переключение рабочего ярлыка не выполнялись.
- Пока настроен Edge, перед переходом на локальный резерв Astra сначала пробует Edge-сервис; первая попытка может передать туда текст ответа согласно текущим настройкам.

Beta.5 остаётся непубличным кандидатом; GitHub release не создавался.
