# Astra Desktop Preview

Запуск из исходников: двойной щелчок по `start_astra_app.vbs`.
Запуск переносимой сборки: двойной щелчок по `Astra.exe`. Python и PowerShell для этого не нужны. Папку `runtime` и `config` нужно держать рядом с exe.

## Что доступно

- мастер первого запуска выбирает имя/2D-персонажа и профиль ИИ; «Пока пропустить» запоминается в отдельном DPAPI-файле и карточка не возвращается при следующем старте. Без настройки профиль не создаётся, запуск остаётся текстовым, микрофон выключен.

- тёмное окно, чат, быстрые команды, анимированный портрет выбранного аниме-персонажа; при речи показывается отдельный оригинальный кадр с открытым ртом, при молчании возвращается портрет с закрытой улыбкой;
- в настройках можно открыть отдельный 3D-preview текущего выбранного мужского или женского образа; Godot 4.7.2 входит в portable ZIP и не требует установки/PowerShell;
- существующие команды Astra через изолированный runtime;
- явное переключение текстового/голосового режима и пауза;
- микрофон выключен при запуске;
- кнопка «Файлы»: выбрать папку на сессию, искать по имени и локально читать UTF-8-текст, PDF, DOCX, XLSX и PPTX;
- чтение файлов локальное, без отправки содержимого в LLM;
- двойной щелчок по выбранному PNG/JPEG/BMP/GIF/WebP открывает локальный preview. Ограничения: файл до 10 МБ, изображение до 16 Мпикс/8192 пикселей на сторону; результат уменьшается до 1600 px, метаданные удаляются, GIF показывает первый кадр. OCR и отправки в ИИ нет;
- границы папки, блокирование `.env`, ключей, symlink и junction;
- остановка собственного runtime при закрытии окна.
- личная память: явно сохранённые заметки, локальное шифрование Windows DPAPI, просмотр и забывание;
- локальная резервная копия памяти хранит DPAPI-шифротекст для этой учётной записи Windows; отдельная переносимая копия шифруется парольной фразой и подходит для другого ПК;
- структурированные события состояния и распознанная голосовая фраза в чате.
- файловые операции: отдельное разрешение записи, preview и подтверждение создания файлов и папок, копирования/перемещения/замены;
- в dev.17 локальный Ollama может предложить до 8 шагов поиска, чтения, копирования, перемещения, переименования файла в той же папке и создания пустой папки; любые изменения требуют временного write grant, точного preview и отдельного подтверждения; модель не может удалять или перезаписывать;
- отправка обычного выбранного файла в Корзину Windows требует отдельного session-разрешения и подтверждения; несколько hardlink не позволяют выйти за выбранную папку;
- журнал и откат через `.astra-history` в выбранной папке; изменённые пользователем результаты не перезаписываются при откате.
- кнопка «ИИ»: выбор локального Ollama, облачного провайдера, режима .env или полного отключения ИИ;
- отдельная вкладка «Разрешения навыков»: просмотр, отзыв и сохранение scopes; отзыв проверяется перед запуском действия;
- профиль и ключ сохраняются в LocalAppData через Windows DPAPI, без редактирования PowerShell/.env;
- локальный диалог хранит до четырёх пар реплик в памяти процесса, очищается при перезапуске runtime.
- в настройках есть вкладка разрешений: приложения, браузер, папки, медиа, окна, ввод текста, системные сведения, VPN и режимы;
- проверка выполняется до dispatch и для шагов routine. Legacy-навыки по умолчанию сохраняют прежние разрешения; файловая запись и память требуют отдельного согласия;
- закрытие приложений: только обычный запрос WM_CLOSE точному процессу. Если несколько окон — выбирается активное подходящее; иначе нужна явная фокусировка. Force-kill fallback отключён.
- «Задачи»: постоянные напоминания с просмотром, отменой и отметкой прочтения; текст хранится через DPAPI. Переносимая копия охватывает ожидающие и непрочитанные задачи, шифруется парольной фразой и повторно защищается DPAPI при импорте;
- команда «Астра, напомни через пять минут сделать перерыв» работает локальным парсером, без обращения к модели;
- «В системный трей» скрывает окно, сохраняя runtime и напоминания. Нажатие на значок возвращает окно, правое меню позволяет завершить приложение. Крестик окна завершает Astra;
- правое меню трея показывает явное действие «Включить микрофон» или «Выключить микрофон» согласно текущему режиму; выбор меняет режим через основной UI-поток, сам трей не открывает аудиоустройства;
- когда главное окно скрыто, tooltip трея показывает только режим и короткий голосовой статус («слушает», «распознаёт речь», «думает», «говорит»); текст распознанной речи или ответа в tooltip не передаётся;
- «ИИ, голос и разрешения → Разрешения навыков» содержит экспорт/импорт профиля. Копия шифруется AES-GCM с ключом PBKDF2-HMAC-SHA256 (600000 итераций) из отдельной парольной фразы от 12 символов; файл не содержит открытых полей профиля. Импорт требует расшифровки и подтверждения замены; память и напоминания в файл не входят. Потерянную парольную фразу восстановить нельзя;
- уведомление в трее содержит только общий текст, без содержимого личного напоминания. Windows может скрывать уведомления в режиме фокусировки.
- «Файлы → Вопрос по выбранным файлам»: Ctrl/Shift позволяет выбрать до пяти документов в той же разрешённой папке; отдельное согласие отправляет только найденные фрагменты локальному Ollama, общий предел — 200000 символов и 2000 символов контекста, каждый фрагмент показывает файл и строки/страницы/слайды; перед показом ответа повторно проверяются все выбранные файлы, облачная отправка недоступна.
- «ИИ, голос и разрешения»: локальный выбор устройства Windows для распознавания, установленного SAPI-голоса, имени ассистента, скорости и громкости озвучки. «Обнаружить» опрашивает устройства локально, «Прослушать» воспроизводит короткую тестовую фразу по команде. После сохранения нужен запуск голосового режима; микрофон не включается при старте.

Текстовые команды: «Астра, сколько времени», «Астра, помощь», «Астра, открой блокнот».

## Текущие ограничения

Текущая сборка — Astra 2.1 Beta (2.1.0-beta.1). Номер продуктовой линейки обновлён по просьбе Егора; незакрытые критерии приёмки перечислены в docs/BETA_ACCEPTANCE.md. В настройках можно выбрать два женских и два мужских оригинальных 2D-образа и сразу увидеть портрет и имя до сохранения. Имя и SAPI-голос хранятся отдельно для каждого персонажа, имя можно заменить своим. Dev.19 добавил каждому образу отдельный кадр речи; dev.20 циклически меняет закрытый и открытый кадры во время реального состояния «Говорю», кэшируя оба изображения. Это визуальная анимация речи, пока без анализа громкости или фонем. Кнопка 3D-preview открывает отдельное окно с текущим несохранённым выбором; переносимая сборка включает Godot runtime и процедурный прототип. В dev.15 он получает состояния ожидания, прослушивания, распознавания, речи и ошибки по токенизированному loopback-каналу. В dev.31 мужские и женские прототипы получили разные пропорции плеч/лица/глаз и простое моргание. Это ещё не production-модели: качество 3D, GPU-нагрузку, phoneme lip-sync и встроенный renderer нужно проверить и улучшить. В dev.17 локальный Ollama может предложить план поиска/чтения/копирования/перемещения/переименования/создания пустой папки. Dev.18 добавляет локальное сравнение до пяти явно выбранных документов; Ollama получает только найденные фрагменты после согласия, ответы показывают источники, а изменения документов блокируют показ ответа. Для любых файловых изменений требуются write grant, точный preview и отдельное подтверждение. Удаление и перезапись через ИИ недоступны. В dev.21 добавлена сборка user-level Inno Setup для установки без UAC; автообновлений и мобильной синхронизации пока нет. Dev.29 добавил экспорт выбранной памяти в AES-GCM-копию под отдельной парольной фразой и импорт на другом ПК с повторным шифрованием под DPAPI; фразу нельзя восстановить, парольная копия не содержит профиль ИИ или напоминания. Журналы runtime хранятся в `%LOCALAPPDATA%` вне каталога приложения. Dev.22 добавил необязательную карточку первого запуска; dev.23 превращает её в трёхшаговый мастер персонажа/имени, выбора ИИ и приватности. Профиль сохраняется только по кнопке «Готово»; настройка не запускает сеть, не скачивает модели и оставляет микрофон выключенным. Для Ollama используется только localhost; голос включается позже отдельной кнопкой. Реальную голосовую, визуальную и корзинную проверку оставили до возвращения пользователя.

Напоминания срабатывают только при запущенной Astra (в том числе в трее). После перезапуска просроченные доставляются в чат, уже доставленные остаются в списке непрочитанных. Автозапуск Windows не включается. При выключенном ПК/закрытом приложении уведомлений нет. Команда не запускает приложения, скрипты или другие действия: сохраняется только текст. При создании голосом/текстом поддерживаются секунды, минуты и часы до 30 дней; UI позволяет выбрать дату. Текст зашифрован, время и статусы в SQLite не зашифрованы. Создание можно отключить в разрешениях; отмена и просмотр остаются доступны. Лимит — 500 ожидающих напоминаний; список показывает последние 1000 записей.

В переносимой сборке голос использует системный SAPI, а распознавание по-прежнему Google Web Speech и требует сеть. Для облачных ответов создать локальный `.env` по `.env.example` и настроить ключ. Реальный `.env` из проекта никогда не включается в сборку. Сборка не подписана сертификатом.

Чтение поддерживает UTF-8-текст до 1 МБ и PDF/DOCX/XLSX/PPTX до 25 МБ; PDF ограничен 200 страницами, извлечённый текст — 1 МБ. Сканированные PDF и изображения внутри документов требуют будущего OCR. DOCX читает основной текст и таблицы; XLSX показывает адреса ячеек, текст и сохранённые значения формул без перерасчёта/форматирования; PPTX извлекает текст слайдов в порядке показа без заметок, диаграмм и вложений. Другие бинарные/старые Office-форматы пока не извлекаются. Поиск ограничен 500 результатами и 10000 просмотренными файлами. Разрешение пропадает при закрытии файлового окна.

Вопросы по файлу требуют явно выбранного Ollama в «ИИ» и согласия в отдельном окне. Лексический поиск работает по одному выбранному файлу до 200000 символов, передаёт до двух фрагментов в пределах 2000 символов; это не полный анализ всего документа и не семантический индекс. Для краткого пересказа используется ограниченная выборка. Цитаты показываются отдельно от ответа, модель может ошибиться. Закрытие окна/снятие согласия отзывает разрешение и отбрасывает результат; уже переданный локальной модели запрос может завершаться до 120 секунд. В одном окне одновременно выполняется один запрос. История/индекс файлов не сохраняются. На текущем ПК синтетический факт найден за 40.62 секунды; скорость зависит от модели и нагрузки.

Запись обычных файлов ограничена 16 МБ; можно создавать пустые папки внутри выбранного корня, но родительская папка уже должна существовать. Папки требуют того же временного разрешения, точного preview и подтверждения. Отмена создания папки сохраняет пустую папку в `.astra-history`; если в ней появились данные, автоматическое восстановление останавливается. В Корзину можно отправить только один явно выбранный обычный файл после отдельного временного разрешения и подтверждения; массовые удаления/изменения пока не реализованы. Журнал и резервные копии локальны и не зашифрованы отдельно от исходной папки; не удаляй `.astra-history`, если нужен откат. Кнопка проверки незавершённой операции сверяет файлы с durable journal после сбоя: обновляет только статус, не меняет содержимое файлов. Конфликт с более поздними правками останавливает recovery. Проверены имитации сбоев процесса; устойчивость к внезапному отключению питания/неисправности диска не заявляется.

## Разработка

Сборка: `.venv\Scripts\python.exe tools\build_desktop.py` (зависимости в requirements-build.txt).
Проверки: `.venv\Scripts\python.exe tools\test_desktop_and_workspace.py` и `tools\run_current_gate.ps1`.

Сборки создаются отдельно, с временной меткой, без перезаписи предыдущих.

Память хранится в `%LOCALAPPDATA%\AstraVoiceAssistant\memory.sqlite`. DPAPI привязывает её к учётной записи Windows: простое копирование базы или локальной резервной копии на другой ПК/профиль не позволяет расшифровать заметки. Для переноса используйте отдельные кнопки «Создать/Восстановить переносимую копию»: файл шифруется AES-GCM ключом из парольной фразы (PBKDF2-HMAC-SHA256, 600000 итераций, минимум 12 символов), при импорте данные заново шифруются DPAPI текущего аккаунта. Приложение показывает preview и требует подтверждение; совпавшие ID не заменяются. Потерянную парольную фразу восстановить нельзя. В переносимый файл входят только заметки, не настройки ИИ или напоминания. По умолчанию заметки не передаются в LLM. В «ИИ» можно явно разрешить их использование только локальным Ollama. Заметки не расширяют права команд; при изменении/забывании заметок старый контекст диалога очищается перед следующим запросом. Уже выполняющийся запрос мог получить прежний контекст до удаления.

Профиль ИИ хранится в `%LOCALAPPDATA%\AstraVoiceAssistant\settings.dpapi`. До явного сохранения профиля применяется прежний .env/default режим. Для Ollama нужен уже работающий локальный сервер и установленная модель; adapter не скачивает модели и не переключается на облако при ошибке. Настройки сохраняются отдельно от переносимой сборки. Качество и скорость локальной модели требуют проверки на конкретном ПК.

Сохранённый профиль и разрешения действуют также при обычном консольном или скрытом запуске runtime. Developer-режим ASTRA_IGNORE_DESKTOP_SETTINGS=1 существует для изолированных тестов; это не голосовая команда и не доступно модели.


Кнопка «Журнал» показывает до 200 последних событий (в базе максимум 5000). Записываются только время, фиксированный тип действия, статус и ID операции. Runtime показывает допуск/блокировку dispatch; это не подтверждение результата WinAPI. Файловые планы записывают результат каждого шага. Beta 3 добавила записи прямых файловых операций, Корзины, undo и recover. Диагностический форматтер маскирует типовые ключи/token/password/Bearer и PEM private key; распознанные фразы и ответы в основных точках логирования заменены числом символов. Это не гарантирует распознавание произвольных секретов в свободном тексте сторонней ошибки. Старые уже записанные логи не переписываются. Текст команд, пути и содержимое файлов в actions.sqlite не записываются.


Версия 2.1 обновляет интерфейс: общий тёмный стиль, таблица истории, память с поиском и двумя колонками, прокручиваемые настройки и закреплённые действия голоса. Подробнее: docs/RELEASE_NOTES_2.1.md. Визуальная приёмка остаётся открытой.
