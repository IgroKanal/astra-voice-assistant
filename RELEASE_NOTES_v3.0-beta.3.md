# Astra 3.0 Beta.3 — локальный кандидат

- **Версия:** `3.0.0-beta.3`
- **Статус:** локальная рабочая версия; не опубликована и не объявлена готовой Beta.

## Новое

- Голосовой вопрос можно отправить в ограниченную фоновую очередь: «Астра, спроси в фоне …».
- Фоновая задача использует только явно выбранный локальный Ollama. Облачного fallback нет.
- Вопрос получает отдельный чистый контекст: история диалога и личные заметки отключены.
- За один запуск Astra допускаются три незавершённых вопроса и один последовательный worker. Есть ограничение времени на задачу и на сетевые ожидания.
- Можно запросить список и состояние задач, получить ответ по номеру и отменить активную задачу.
- Текст вопроса и результат остаются в памяти процесса и удаляются при завершении Astra. Уведомление о готовности не содержит вопрос или ответ.
- Вызовы фоновых действий типизированы; LLM-маршрутизатор не может создать их без голосовой команды.

## Ограничения кандидата

- Фоновые вопросы доступны, только когда Ollama включён и явно выбран в настройках. Модель не скачивается автоматически.
- Это локальная очередь на время текущего запуска, без веб-исследования, переноса между запусками и долговременного планировщика.
- Полный локальный автоматический gate пройден: 316 тестов, compileall/py_compile, 10 smoke-проверок, 4 config validators и Astra Doctor. Portable ZIP прошёл проверку состава и секретов; installer прошёл изолированную проверку установки/runtime/uninstall с сохранением пользовательских данных. Реальный микрофон, работа с установленной моделью и оценка качества/задержки остаются открытыми.
