# Точные критерии следующих beta

Статус 2026-11-13: текущая сборка — **Astra 2.4 Beta** (`2.4.0-beta.1`). Ночные изменения `1.4.0-dev.1–31` вошли в 2.0 Beta; версии 2.1–2.3 отмечают этапы интерфейса, 2.4 — межпроцессную защиту от перезаписи занятого имени. Непройденные продуктовые gates сохраняются открытыми.

В текущем preview уже есть постоянные текстовые напоминания с отменой/непрочитанными состояниями, нативный tray, вопросы по явно выбранным документам через локальный Ollama, прокручиваемый центр разрешений и безопасный отказ при гонке за новым именем файла между процессами. Это не закрывает проверку замен существующих файлов и подмены родительских каталогов. Произвольные фоновые рутины, семантический индекс, другие офисные/медиа форматы, полная доступность и ручная приёмка остаются отдельными задачами.

## v2.0 Beta

- [x] Начальные типы плана/шага/результата, отказ неизвестному навыку и schema validation.
- [x] Read-only grant пользовательской папки и проверки traversal/reparse/secret paths.
- [x] Отмена между шагами, остановка на первой ошибке, максимум 8 шагов.
- [x] Unit/integration tests и локальная Windows CI-конфигурация.
- [x] Runtime app/window/media/system и routine steps проходят общий ActionPolicy перед dispatch; разрешения сохраняются в profile и действуют для desktop/console/hidden.
- [x] Настройки grants в UI с просмотром и отзывом; Windows UI test сохраняет отзыв в изолированный DPAPI профиль и подтверждает блокировку действия.
- [x] Создание файлов до 16 МБ и пустых папок; копирование/переименование/перемещение/замена файлов до 16 МБ с preview, отдельным session write grant и recoverable undo.
- [x] Восстановление журнала незавершённых операций после сбоя процесса для файлов и пустых папок; конфликт с более поздними данными останавливает авто-откат.
- [x] При атомарном создании файла конкурентный процесс не может занять имя незаметно: отдельный Windows-процесс создаёт назначение перед `os.link`; Astra сохраняет его данные, отмечает операцию как отменённую и убирает временный файл.
- [ ] Конкурентные изменения существующего файла и подмена родительских каталогов между процессами ОС требуют отдельного безопасного механизма и остаются открытыми.
- [x] Удаление доступно только как отправка отдельного выбранного файла в Корзину Windows; отдельный session-grant, preview, подтверждение, повторная проверка и hardlink защита.
- [ ] Журнал действий с редактированием секретов и схемой миграций.
- [ ] Регрессионный и ручной gate принят.

## v3.0 Beta

- [x] Явные зашифрованные локальные заметки: сохранить/найти/забыть.
- [x] Заметки подключены к локальному диалогу с явным согласием и отзывом; облачный путь не читает память.
- [ ] Provider abstraction и приватный/offline маршрут модели.
- [x] Базовый RAG по разрешённому UTF-8/PDF/DOCX/XLSX/PPTX документу через локальный Ollama; цитаты остаются недоверенными, есть injection tests для TXT/DOCX/XLSX.
- [ ] OCR/таблицы/остальные офисные форматы, семантический индекс и широкая eval-выборка.
- [x] Ограниченный локальный планировщик принимает только точную JSON-схему для files.search/files.read_text; невалидные поля, traversal, неизвестные навыки и управляющие символы блокируются.
- [x] В файловом UI локальная модель получает запрос только после отдельного согласия; документы ей не передаются. План требует симуляции актуальных шагов и отдельного подтверждения.
- [ ] Реальная Ollama-модель должна пройти пользовательскую оценку качества запросов; общие desktop actions, risk scoring и долгие budgeted workflows не реализованы.
- [ ] Рутины, фоновые задачи и уведомления с отменой.
- [ ] Eval-набор реальных пользовательских команд.

## v4.0 Beta

- [x] Отдельное Windows-окно и переносимый EXE без проектного Python.
- [x] 2D-персонаж и события listening/recognizing/speaking.
- [x] Текст/голос/пауза; микрофон выключен по умолчанию.
- [x] Начальная пара оригинальных 2D-аниме-портретов мужского и женского персонажей; DPAPI-профиль хранит выбранный образ, отдельное имя и голос для каждого персонажа и собственное имя ассистента.
- [ ] Полный набор выбираемых аниме-персонажей с разными именами/голосами и финальная художественная приёмка.
- [ ] Раздельный выбор 2D/3D, preview образа и автономный выбор голоса; офлайн-рендеринг и лицензии проверены.
- [ ] Финальный UI-стек и дизайн согласованы на реальной визуальной проверке.
- [x] Нативный tray и необязательный мастер первого запуска; настройки сохраняются только по явному завершению, микрофон не включается автоматически.
- [x] Центр разрешений показывает отдельные прокручиваемые карточки навыков; действия сохранения и резервного копирования остаются видны на небольшом экране.
- [ ] Полная доступность, включая ручную проверку клавиатурой, экранным диктором и визуальный контраст.
- [x] Базовый выбор установленного микрофона и SAPI-голоса, имени ассистента, скорости/громкости и локальный SAPI preview.
- [ ] Управление устройствами ввода/вывода и голосом с VAD/push-to-talk в UI.
- [ ] Установщик, подписанные обновления и rollback.
- [ ] Sleep/resume, crash recovery, многократный запуск и длительная работа проверены.
