# Будущий безопасный импорт персонажей

Произвольный импорт 2D/3D-персонажей **не реализован** в Astra 3.1. Это отдельная продуктовая функция, а не скрытая настройка.

Перед реализацией нужен signed/manifest-based пакет `.astra-avatar` с версией схемы, именем, автором и лицензией, статическими PNG/WebP кадрами для 2D и GLB без внешних ссылок для 3D. Пакет должен проходить проверку размера, числа файлов, размеров текстур, polygon/animation budgets и канонических путей до показа. ZIP-slip, symlink/reparse, абсолютные пути, executables, scripts, shaders с файловым/сетевым доступом и внешние ресурсы отклоняются.

Preview должен выполняться в изолированном процессе с fixed executable, одноразовой loopback-аутентификацией, без микрофона, capability grants и доступа к пользовательскому workspace. Пользователь отдельно подтверждает лицензию и сохранение. Ошибка проверки оставляет встроенный 2D-профиль активным. Production gate включает GPU fallback, отмену импорта, удаление пакета и тесты malformed/hostile assets.
