# Astra 3.0 Beta

- **Кандидат:** `3.0.0-beta.1`
- **Статус:** рабочая сборка; релиз не опубликован.

## Возможности этого этапа

- Голосовые заметки сохраняются и ищутся локально; удаление выполняется только при одном точном совпадении. Для них отдельно включается личная память.
- Голосовой поиск показывает имена только внутри выбранной пользователем папки. Требуются wake-фраза и отдельное разрешение; поиск не читает содержимое файлов.
- Голосовое открытие требует отдельного разрешения и точного полного имени. Astra открывает только один найденный документ или медиафайл. Исполняемые файлы, ссылки и неоднозначные совпадения блокируются.
- Чтение вслух выбранного документа — отдельный навык и разрешение, выключенное по умолчанию. Оно работает по точному имени и только в выбранной папке, читает ограниченный отрывок поддерживаемого документа через локальный Windows SAPI и не добавляет текст в чат и не отправляет его в LLM или облачный синтез.
- После каждого отрывка до 1600 символов можно сказать «Астра, прочитай дальше». Курсор действует три минуты и только для той же открытой выбранной папки; текст между запросами не хранится.
- Голосовой вопрос по документу использует точное имя одного файла в выбранной открытой папке и отдельное разрешение `ask_files`, выключенное по умолчанию. Вопрос отправляется только выбранному локальному Ollama с ограниченными цитатами из документа; ответ произносится приватно через Windows SAPI и не появляется в чате/журнале и не проходит через облачный TTS. Закрытие папки или переключение режима отменяет ответ.
- Голосовые команды поиска, открытия и чтения не маршрутизируются в LLM. Единственное содержательное исключение — явно произнесённый вопрос по одному документу, который передаётся локальному Ollama только при включённом разрешении `ask_files`; абсолютные пути не передаются.
