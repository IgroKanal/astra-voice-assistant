# Точные критерии следующих beta

Статус 2026-11-14: текущая локальная сборка — **Astra 3.1** (`3.1.0`), не опубликована. Это содержательный этап после 3.0: добавлено ограниченное чтение ODT/ODS/ODP. Полный локальный gate прошёл: 344 теста, 9 smoke-проверок, 4 config validators и Astra Doctor. Windows CI с portable ZIP и Setup installer, ручная проверка реальных документов, микрофона, голоса и задержки остаются открытыми; релиз не объявлен.

После чтения документов и SAPI-замеров коммит `03e3272` прошёл Windows CI `43544336055`, включая встроенный runtime, portable ZIP и интеграционный тест установщика. Продолжение приватного чтения прошло свежий локальный gate: 282 теста, 9 smoke, 4 config validators и Astra Doctor; Windows package CI этой ревизии `43546387923` тоже прошёл.

В текущем preview уже есть напоминания с отменой/непрочитанными состояниями, native tray и вопросы по явно выбранным документам через локальный Ollama. Остались OCR, старые Microsoft Office-форматы, другие медиаформаты, полноценная доступность и ручная голосовая приёмка.

## Astra 3.0 Beta · быстрый и ограниченный голосовой контур

- [x] После подтверждённой wake-фразы фоновый warmup касается только установленной Ollama-модели; не скачивает модель и не активируется на случайной речи.
- [x] Короткий warmup отключаем (`OLLAMA_WARMUP_ON_WAKE=false`), запросы Ollama сериализованы, локальный ответ по умолчанию идёт без thinking.
- [x] Фоновый warmup кеширует список и возможности уже установленной Ollama-модели; конкурентные запросы используют общие результаты и не дублируют /api/tags или /api/show.
- [x] Полный локальный gate после кеширования: компиляция, 307 unit/integration/UI тестов, 10 smoke tests, 4 config validators и Astra Doctor.
- [x] STT ограничен сетевым тайм-аутом по умолчанию 12 секунд; TTS использует общий лимит 25 секунд для основного и резервного голоса. Значения можно менять в `.env`.
- [x] STT timing разделяет запись, сетевое распознавание и общий путь; строка замера не содержит transcript.
- [x] Edge TTS при cache miss не делает предварительную повторную генерацию; резервный голос получает только остаток общего временного бюджета.
- [x] Файловые поиск и чтение внутри плана проверяют отмену и общий временной budget между элементами обхода и этапами разбора PDF, DOCX, XLSX и PPTX; отдельный файловый системный/парсерный вызов нельзя прервать посередине.
- [x] Отмена или отзыв доступа в File RAG передаётся в чтение, отбор фрагментов и потоковый локальный запрос Ollama; отмена закрывает соединение, а частичный ответ не показывается.
- [x] File RAG отклоняет ссылки на невыбранные фрагменты, сохраняя проверку актуальности исходных файлов.
