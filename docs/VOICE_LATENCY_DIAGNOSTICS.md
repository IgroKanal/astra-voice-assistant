# Локальная диагностика скорости голоса

`tools/latency_report.py` читает один явно выбранный лог и печатает только p50/p95 и число замеров для STT, локального/облачного ответа LLM, первого токена локальной Ollama и TTS. Замер первого токена включён только для обычного локального ответа; текст, команды, документы и сообщения в timing-строку не попадают. Отчёт не показывает содержимое логов и ничего не отправляет. Максимальный размер лога — 25 МБ; ссылки и reparse-файлы отклоняются.

Запуск после ручной голосовой проверки:

```powershell
python tools\latency_report.py "ПОЛНЫЙ_ПУТЬ_К_ВЫБРАННОМУ_ЛОГУ"
```

Для локальной Ollama Astra запрашивает потоковый ответ и фиксирует время до первого непустого фрагмента. Если выбран Edge TTS и скрытые рассуждения выключены, после первого безопасного завершённого предложения начинается озвучивание, пока Ollama продолжает генерировать ответ; остаток звучит после окончания генерации. Если ранняя озвучка не удалась, Astra произносит полный ответ обычным путём. Содержимое первого предложения отсекается при обнаружении маркеров рассуждений, черновика, разметки или кода. Фоновый warmup заранее читает список и возможности уже установленной модели Ollama; при конкурентном запросе оба потока используют общий кеш, не создавая повторные запросы /api/tags и /api/show. Отчёт суммирует timing-записи и не измеряет задержку от wake-фразы до первого слышимого звука; ручная проверка микрофона и реального голоса всё ещё требуется для закрытия 3.0 Beta gate.
