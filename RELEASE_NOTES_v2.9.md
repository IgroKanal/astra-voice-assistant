# Astra 2.9 Beta

**Версия:** `2.9.0-beta.1`

## Что изменилось

- В настройках локального Ollama можно отдельно включить распознавание поддерживаемых команд локальной моделью.
- Функция выключена по умолчанию. Она использует только уже установленную модель и не скачивает новую.
- В локальном маршруте нет облачного fallback. Сбой модели или некорректный JSON даёт безопасный отказ.
- Возвращённое намерение остаётся ограниченным типом действия и проходит общую проверку разрешений и runtime dispatch.

## Границы проверки

Автотесты проверяют профиль и UI, opt-in, локальный маршрут, отказ при ошибке и отсутствие создания или вызова облачного клиента. Реальное качество зависит от установленной модели; голосовую и визуальную приёмку должен выполнить пользователь. Astra 2.9 остаётся Beta и не закрывает общие критерии v2–v5.
