# Проверка визуальной рабочей копии Astra 3.1

Дата: 2026-11-15.

## Автоматические проверки Qt-оболочки

- `tools/test_qt_desktop.py`: 25 тестов успешно. Покрыты голосовой центр как стартовый экран, пять разделов, полноэкранный boot-слой, фоновый сценарий закрытия, desktop-персонаж, мгновенный предпросмотр смены образа, закреплённая кнопка сохранения, явный запуск микрофона, clipboard shortcuts, DPAPI-настройки, сворачиваемое подключение ИИ, аудио и scopes, onboarding, каталог, журнал, временные файловые grants, симуляция плана, отзыв доступа, explicit preview success flag, voice file IPC без workspace, подтверждение импорта профиля, слоистая 2D-анимация, состояния и reduced motion персонажа, а также наличие прозрачных RGBA full-body ассетов для всех профилей.
- `py_compile` для `astra_desktop_qt.py`, `src/qt_theme.py`, `src/qt_widgets.py`: успешно; полный gate также компилирует зависимые Qt-файлы, старый Tk fallback и runtime.
- `tools/capture_qt_preview.py`: успешно без микрофона, сети и личных данных. Созданы и визуально проверены `home.png`, `dialogue.png`, `tasks.png`, `desktop-character.png`, `settings.png`, `launch-animation.png`, `files.png`, `file-operations.png`, `onboarding.png`, `command-catalog.png` и `character-speaking.png` в `visual_previews_qt/`. На preview персонаж показан в полный рост от головы до обуви, без чёрного фонового прямоугольника и без обрезки ног; основной интерфейс имеет минималистичную cyan/glass навигацию.
- `tools/run_current_gate.ps1`: успешно; 373 unit/integration tests, smoke checks, config validators и Astra Doctor. Repository-only git-проверки в handoff без `.git` не выполняются и должны быть повторены после возврата копии в Git-репозиторий.
- Общая Qt-тема применяется к главному окну и отдельным `QDialog`; длинные главная и настройки прокручиваются. Стандартной Tk-компоновки в Qt preview нет.

## Персонажи

- Основные 2D-ассеты — цельные полноразмерные референсы пользователя (`full_female.png`, `full_male.png`, `full_female_saya.png`, `full_male_kai.png`), сохранённые с прозрачным фоном. Они соответствуют исходным лицам, причёскам, костюмам и цветам Мику, Рэна, Саи и Кая. Оригинальные бюсты оставлены в `assets/avatars/` как fallback.
- Qt-сцена разделяет full-body арт на слои «тело/голова» с увеличенным перекрытием против шва: тело и голова движутся отдельно, есть дыхание, циклы поз, кивки, эмоциональные метки состояний, отражение у пьедестала, орбитальные частицы и состояние свечения/колец. При речи используется кадр с локально добавленным открытым ртом и двойная волна у рта. Двойной клик по desktop-персонажу открывает синхронизированный полноэкранный 2D-просмотр, закрываемый Esc.
- 3D-направление временно отложено: процедурный OpenGL/Godot blockout не прошёл художественную приёмку и убран из пользовательского Qt-интерфейса. Для продолжения нужны настоящие 3D-модели персонажей (GLB/VRM или аналог). Runtime-проверка Godot не выполнялась, потому что verified Godot 4.7.2 executable отсутствует в текущем handoff.

## Package gate

Portable ZIP, relocated package, EXE и Setup installer **не собраны**. `tools/build_desktop.py` по-прежнему остановится обязательной проверкой verified Godot 4.7.2 Windows executable через `ASTRA_GODOT_EXECUTABLE`; сборка также не выполнялась без явного запроса пользователя. Интегрированные build/validate scripts не считаются фактическим прохождением package gate.

## Открытые ручные gates

Художественная приёмка полноразмерных 2D-персонажей, покадровые full-body speaking-арты, будущие настоящие 3D-модели, выбор имени и голоса пользователем, реальный микрофон и Windows TTS, Windows 10/11 на физических DPI 100/125/150%, длительная работа, portable relocated runtime и Setup install/uninstall. Пользовательский ярлык и установленная копия Astra не изменялись.
