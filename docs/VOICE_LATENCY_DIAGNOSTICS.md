# Локальная диагностика скорости голоса

`tools/latency_report.py` читает один явно выбранный лог и печатает только p50/p95 и число замеров для STT, локального/облачного ответа LLM и TTS. Содержимое строк, команд, документов и сообщений не показывается и никуда не отправляется. Максимальный размер лога — 25 МБ; ссылки и reparse-файлы отклоняются.

Запуск после ручной голосовой проверки:

```powershell
python tools\latency_report.py "ПОЛНЫЙ_ПУТЬ_К_ВЫБРАННОМУ_ЛОГУ"
```

Скрипт не включает новые замеры и не измеряет задержку от wake-фразы до первого слышимого звука. Он суммирует только timing-записи, которые уже присутствуют в логе. Для закрытия 3.0 Beta gate всё ещё требуется ручной тест Егора на реальном микрофоне и голосе.
