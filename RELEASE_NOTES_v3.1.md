# Astra 3.1 — OpenDocument-файлы

- **Версия локальной сборки:** 3.1.0
- **Статус:** локальный непубликованный этап. Автоматический gate прошёл; сборка Windows package и интеграционная проверка установщика в GitHub CI ещё ожидаются. Реальные документы, микрофон и голосовую оценку должен проверить пользователь.

## Изменения

- В выбранной пользователем папке можно читать ODT, ODS и ODP и безопасно открывать единственный выбранный документ этих типов.
- ODT: заголовки, абзацы, списки и табличный текст в порядке документа. Комментарии, удалённый текст и tracked changes исключены.
- ODS: листы и ячейки в исходном порядке, адреса ячеек, текст и сохранённые значения/формулы. Формулы не вычисляются; повторяющиеся строки/столбцы и общее число ячеек ограничены.
- ODP: текст по порядку слайдов; заметки докладчика не включаются; количество слайдов ограничено.
- Файлы читаются внутри ZIP без извлечения на диск и исполнения. Отклоняются DTD/ENTITY, чрезмерное сжатие и превышение ограничений размера/объёма; обработка проверяет отмену.
- Новые файловые разрешения и возможности UI не добавлялись. Дизайн приложения, персонажи, ярлыки и настройки пользователя не менялись.

## Проверки

- Полный локальный автоматический gate: **344 теста**, компиляция Python, 9 smoke-проверок, 4 config validators и Astra Doctor — пройдены.
- Doctor показывает только прежнее некритичное предупреждение об отсутствующей службе AmneziaWG.
- Windows CI, portable ZIP и Setup installer validation ожидают отправки ревизии в существующую рабочую ветку.
- Ручная проверка чтения личных документов, микрофона, фактического звучания и end-to-end задержки не выполнялась.

Следующий продуктовый этап планируется как **Astra 3.2** с измеримым улучшением скорости и устойчивости голосового ответа. Номер будет повышен после реализации и полного gate следующего этапа.
