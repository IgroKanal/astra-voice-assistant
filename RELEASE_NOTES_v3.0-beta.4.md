# Astra 3.0 Beta.4 — локальный кандидат

- **Версия:** `3.0.0-beta.4`
- **Статус:** локальная рабочая версия; не опубликована. Автоматический gate, portable ZIP и установщик прошли локальные проверки.

## Новое

- Голосовое чтение в выбранной папке расширено на CSV/TSV/JSON/JSONL, YAML, TOML, INI/CFG/CONF, логи, документационный текст, SQL и распространённые исходные файлы.
- Текстовые файлы читаются в UTF-8, UTF-16 при наличии BOM и CP1251. Размер остаётся ограниченным; содержимое передаётся только в приватную озвучку Windows SAPI по точному имени и активному разрешению `read_files`.
- Скрипты и исходный код можно прочитать как текст, но `read_files` не добавляет их в список голосового запуска. Открытие голосом по-прежнему ограничено прежним безопасным списком документов и медиа.
- Для вопросов по файлам допустимые текстовые расширения доступны только выбранному локальному Ollama при отдельном `ask_files`; облачный маршрут не используется.
- Минимальная версия `edge-tts` поднята до 7.3.1. Старая установленная 7.2.8 возвращала 403 при генерации; после обновления список голосов читается, но синтез в этой среде вернул `NoAudioReceived`. Работоспособность онлайн-озвучки остаётся открытой; активный голос в настройках не переключался.
- Portable-runtime включает локальные `edge-tts.exe` и `edge-playback.exe`, оригинальные исходники helper-библиотеки и её LGPL/MIT license notice. Проверка runtime запускает оба локальных entry point без сетевого синтеза.

## Ограничения кандидата

- Чтение работает только в выбранной папке и требует wake-фразы и отдельного разрешения. Продолжение чтения остаётся ограниченным по длине и времени.
- Не добавлялись бинарные старые Office-форматы, OCR и исполнение команд из файлов. Ручная микрофонная проверка и оценка реальной модели остаются открытыми.
- Реальная генерация Edge TTS и пользовательская оценка доступных голосов не пройдены. Короткий локальный SAPI-образец установленной Ирины создан для прослушивания; это не ручная приёмка и не доказательство качества голоса.
- Полный локальный gate прошёл: 320 unit/integration/UI tests, `compileall` и `py_compile`, 10 smoke tests, 4 config validators и Astra Doctor. Astra Doctor сообщил только некритичное предупреждение о не найденной службе AmneziaWG.
- Portable ZIP прошёл package/secret validation и frozen-runtime/helper checks. Изолированный установщик прошёл install/runtime/LocalAppData/uninstall и helper checks; тестовые пользовательские данные сохранились.
- Реальный микрофон, качество SAPI/локального Ollama и end-to-end задержка до первого слышимого ответа остаются непроверенными вручную. Пользовательский ярлык не менялся; релиз не публиковался.
