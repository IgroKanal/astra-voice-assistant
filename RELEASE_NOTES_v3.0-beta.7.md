# Astra 3.0 Beta.7 — локальный кандидат

- **Версия:** 3.0.0-beta.7
- **Статус:** локальный непубликованный кандидат; полный локальный автоматический gate и Windows CI прошли. Run 43581772695 и 43581779729 собрали и проверили portable ZIP и Setup installer.

## Изменения

- Ответ на вопрос по выбранным документам принимается только тогда, когда модель ссылается на существующий переданный фрагмент.
- Ссылка на отсутствующий фрагмент, как и ответ вообще без ссылок, приводит к отказу выдать неподтверждённый ответ.
- Astra перечисляет в источниках только процитированные моделью фрагменты, с точным именем файла и диапазоном строк. Содержание документа по-прежнему доступно только через отдельное разрешение, выбранную папку и локальный Ollama.

## Проверки

- Полный локальный gate: **335 unit/integration/UI tests**, compileall и py_compile, 9 smoke-проверок, 4 валидатора конфигурации и Astra Doctor.
- Фокусированный File RAG набор: **19 тестов**.
- Осталось прежнее некритичное предупреждение Astra Doctor об отсутствующей службе AmneziaWG.
- Реальные микрофон, голосовое чтение и end-to-end задержка до первого звука остаются открытыми для пользовательской проверки.
- Внешний вид приложения, иконка и 2D/3D-аватары в этом этапе не менялись.
