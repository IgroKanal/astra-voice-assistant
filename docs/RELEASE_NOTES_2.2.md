# Astra 2.2 Beta — файлы и задачи

- Окно задач: таблица срока/статуса/напоминания с прокруткой и областью полного текста.
- Выбор, отмена и прочтение привязаны к ID задачи; выбор сохраняется после обновления.
- Пустой список объясняет, как создать первую задачу. Счётчик показывает ожидающие задачи.
- Окно файлов: заголовок папки, прокручиваемый список, понятный пустой поиск, компактная панель действий в две колонки.
- Просмотр документа: заголовок, отметка чтения без редактирования, отступы и прокрутка.
- Голосовые сообщения пользователя получили то же оформление роли, что текстовые.

UI-тесты пройдены; ручная художественная оценка остаётся открытой. Форматы чтения,
права на файлы, лимиты поиска и подтверждения операций сохраняются.
